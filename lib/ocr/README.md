# OCR no dispositivo (sem CDN)

Ficheiros de terceiros, copiados sem alterações dos pacotes npm (publicados há mais de 14 dias, licenças Apache-2.0 e MIT):

- `tesseract.min.js`, `worker.min.js` — tesseract.js 7.0.0 (https://github.com/naptha/tesseract.js)
- `tesseract-core-*-lstm.wasm.js` — tesseract.js-core 7.0.0 (motor Tesseract compilado para WebAssembly)
- `por.traineddata.gz` — @tesseract.js-data/por 1.0.0, pasta `4.0.0_best_int` (modelo de português)

`SHA256SUMS.txt` tem as somas dos ficheiros. A imagem é lida no próprio dispositivo e não é enviada para lado nenhum.
